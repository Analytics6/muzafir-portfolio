# Video & visual portfolio

Responsive static portfolio for GitHub Pages. Includes five video samples and 26 images from the provided portfolio archive.

## Customize
Edit the name, introduction and GitHub contact links in `index.html`. Gallery titles and categories live in `work.js`. Videos are in `assets/`.

## Publish
Upload this repository to GitHub. In Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**. No build or dependencies are required.

## Preview
Run `python -m http.server 8000` and visit http://localhost:8000.
